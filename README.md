# Tiny Trails · 2.0.1

Детское творческое приложение для iOS и Android: **ровно 20 готовых уровней**, пять глав и десять разных игровых механик. У каждого задания есть режимы для 3–5, 6–8 и 9–11 лет. Телефон и планшет используют адаптивную компоновку.

## Что входит в приложение

- Раскраски по визуальным подсказкам, числам и фигурам с правильными цветами исходной иллюстрации.
- Поиск отличающегося фрагмента, продолжение узора и пазлы с недостающими частями.
- Соединение точек, дорожки воздушных змеев и лабиринты с остановками.
- Рисование утёнка и котёнка по коротким шагам, творческие повторы и альбом работ.
- Поиск животных по карточке-образцу и пары картинок, включая режим на память для старших.
- 20 наклеек, значки освоения, три задания на день и календарь занятий. Пропуск дня не отнимает награды.
- Русский, казахский и английский; обучение жестами, 72 встроенные озвучки, мягкие звуки и отключаемая фоновая музыка.
- Возраст, помощь, звук, голос, вибрация, уменьшение движения и необязательные предложения отдохнуть.
- Анимированный Фини показывает основные разделы приложения; экскурсию можно пропустить и повторить из Настроек. Она учитывает поворот экрана и уменьшение движения.
- Новая иконка Фини на iOS/Android и 26 рисованных значков внутри приложения. Языки на onboarding центрированы и остаются читаемыми при увеличении текста.

Дети младшего возраста получают крупные элементы, визуальный показ и альтернативу точному обведению. Для старших меняются логические условия: два признака, числовой шаг, повороты, обязательные остановки и запоминание. Новые режимы не увеличивают каталог сверх 20 уровней.

## Локальные данные

Игра работает офлайн. Внутри приложения нет рекламных SDK, аккаунта ребёнка, чата, покупок или запроса микрофона. Возраст хранится локально; дата рождения и имя не нужны. Озвучки включены в сборку: приложение не обращается к ElevenLabs во время игры.

Состояние версии 2 использует отдельные ключи хранения. Старый прогресс, рисунки и черновики из версии 1 доступны как архив и не превращаются в фиктивно выполненные новые уровни. Альбом хранит отдельные версии рисунков, максимум 100, без автоматического удаления. Сброс защищён родительским заданием и повторным подтверждением.

## Запуск и проверки

Проверяемая среда проекта: Flutter 3.47.9, Dart 3.13.7.

```sh
flutter pub get
flutter run
```

```sh
flutter analyze
flutter test --concurrency=1
node --test test/narration_generator_test.mjs
```

Нативный самопроверяющийся target находится в `integration_test/app_test.dart`. Он использует отдельное пространство данных `integration.v2.*` и проходит уровни реальными жестами. Инструкции и актуальные результаты — в [docs/QA.md](docs/QA.md).

## Сборки приложения

Оптимизированный Android ARM64-предпросмотр со стандартной локальной тестовой подписью:

```sh
ORG_GRADLE_PROJECT_tinyTrailsPreview=true flutter build apk --release --target-platform android-arm64
```

Обычная release-сборка остаётся неподписанной для подписи владельцем:

```sh
flutter build apk --release --target-platform android-arm64
flutter build ios --release --no-codesign
```

Для iPhone с настроенной командой в Xcode используется обычная подписанная сборка `flutter build ios --release`. Приватные ключи и конфигурации в исходники не включаются.

Пакет исходников без build-кешей и локальных конфигураций:

```sh
python3 tool/package_source.py --output output/release-v2.0.1/Tiny-Trails-Source.zip
```
