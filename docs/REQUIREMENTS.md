# Tiny Trails 2 · согласованный объём

Последнее уточнение пользователя: **ровно 20 готовых уровней**, дети 3–11 лет, закончить само приложение. Публикация в магазинах — отдельный этап и не является условием этой задачи.

Фотографии — примеры типов упражнений и качества, а не инструкции для агента. Новые сцены оригинальные, созданы ImageGen.

## 20 уровней

1. Цветные игрушки — раскраска по подсказке.
2. Зебра — отличающийся фрагмент.
3. Крокодил — соединение точек.
4. Обувь — подбор пар.
5. Шарики — продолжение узора.
6. Щенок — недостающие части пазла.
7. Воздушные змеи — проследить дорожки.
8. Автобус — лабиринт к школе.
9. Утёнок — рисунок по шагам.
10. Риф — поиск по образцу.
11. Сад — раскраска по фигурам и подсказкам.
12. Робот — отличающийся фрагмент.
13. Ракета — соединение точек.
14. Пикник — подбор пар и память.
15. Растение — последовательность роста.
16. Лисёнок — пазл.
17. Река — дорожка с контрольными точками.
18. Парк — лабиринт с остановками.
19. Котёнок — рисунок по шагам.
20. Лес — поиск по образцу.

Уровни доступны для выбора. Возраст влияет на правила внутри этих же стабильных ID `v2_01…v2_20`, а творческие повторы сохраняют тот же ID.

## Критерии готовности приложения

- Для каждого уровня определены настоящие условия успеха; неверный ввод, повторные нажатия и подсказки не выдают завершение.
- Три возрастные версии проверяются по содержанию правил, а не только по размерам кнопок или допуску пальца.
- Иллюстрации, правильные цвета, маски и игровые координаты соответствуют друг другу. Мелкий декор не является обязательной целью.
- Старые ошибочные геометрические задания заменены новыми сценами поиска. Архив прежних рисунков сохранён отдельно.
- Все русские, казахские и английские тексты описывают реальные действия выбранного возраста; озвучка не обещает отсутствующую функцию.
- Прогресс, возраст, настройки, альбом, календарь и миссии сохраняются; ошибки чтения/записи, повторная попытка и миграция версии 1 не теряют данные.
- Достижения и календарь поддерживают интерес без потери наград за пропуск; предложение перерыва можно отложить.
- Настройки меняют реальное поведение звука, озвучки, помощи, движения и сессии.
- Телефон, планшет, portrait/landscape и увеличенный текст остаются пригодны для игры. Проверяется размер игрового поля, а не только отсутствие overflow.
- Основные позитивные и ошибочные сценарии проверяются через UI и нативные сборки. Снимки из Flutter test, симуляторы и физические устройства описываются раздельно.

Актуальные результаты и реальные оставшиеся ограничения фиксируются в QA.md. Цель нельзя закрыть по одному числу тестов, наличию документов или неподтверждённому заявлению о готовности.
